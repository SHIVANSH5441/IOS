 iOS Apps Collection

A collection of four iOS practice apps built in Xcode while learning mobile app development. Each project focuses on a different part of iOS UI design and app interaction.

## Apps

| App | Description | Focus |
| --- | --- | --- |
| **AutoLayout-iOS13** | A practice project for building responsive interfaces that adapt to different iPhone screen sizes. | Auto Layout and constraints |
| **Calculator-Layout-iOS13** | A calculator-style user interface built to practice arranging buttons, labels, and screen layouts. | UI layout and interface design |
| **Dicee-iOS13** | A dice-rolling app that changes the displayed dice when the user interacts with the app. | User interaction and randomisation |
| **Xylophone-iOS13** | A simple musical app that plays different notes when users tap the coloured keys. | Touch handling and sound playback |

## Getting Started

1. Clone this repository.

   ```bash
   git clone https://github.com/SHIVANSH5441/IOS.git
   ```

2. Open the folder for the app you want to run.
3. Open its `.xcodeproj` file in Xcode.
4. Choose an iOS Simulator or a connected iPhone.
5. Press `Cmd + R` to build and run it.
